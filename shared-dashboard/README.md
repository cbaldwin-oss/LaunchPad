# Project Dashboard — Stream (CxAlloy commissioning)

A self-contained **HTML + Plotly** commissioning dashboard for embedding in a
static, auth-proxied web app, plus the pipeline that keeps its data fresh.

> **⚠️ Keep this repository PRIVATE.** `html-dashboard/data/*.json` contains a real
> client's commissioning data. It must sit behind your auth proxy — never public.

## Layout
```
html-dashboard/          # the static dashboard your host serves
  index.html             #   whole dashboard (Plotly, client-side filters + charts)
  data/                  #   view-ready JSON (regenerated by the refresh Action)
  HOSTING.md             #   how to host / embed / wire secrets
sync_logic.py            # CxAlloy → SQLite sync (HMAC-signed API)
export_json.py           # SQLite → trimmed JSON the browser reads
config.py  utils/        # cleaning + config shared with the sync/export
.github/workflows/refresh-dashboard.yml   # hourly data refresh
```

## Data flow
CxAlloy API → (sync, in the Action's runner) SQLite → (`export_json.py`) JSON →
committed to this repo → static host redeploys → browser renders. The CxAlloy HMAC
secret lives only in GitHub Actions secrets; it never reaches the browser.

## Setup
See **[html-dashboard/HOSTING.md](html-dashboard/HOSTING.md)**. In short:
1. Keep the repo private, behind your auth proxy.
2. Add repo secrets `CXALLOY_IDENTIFIER` and `CXALLOY_SECRET`.
3. Point the static host at `html-dashboard/`.
4. Actions tab → "Refresh dashboard data" → Run workflow (hourly thereafter).

## Local preview
```
python export_json.py                 # regenerate data from a local dashboard_data.db
cd html-dashboard && python -m http.server 8765
# open http://localhost:8765/index.html
```
